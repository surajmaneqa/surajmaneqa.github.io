# Suraj Mane - Personal Portfolio

A simple personal portfolio website designed for deployment with GitHub Pages.

## Files

- `index.html` - Main portfolio page
- `style.css` - Website styling
- `script.js` - Small JavaScript enhancements
- `assets/profile.jpg` - Replace with your profile photo
- `assets/Suraj-Mane-Resume.pdf` - Replace with your actual resume

## Customize before publishing

1. Replace `assets/profile.jpg` with your own photo.
2. Replace `assets/Suraj-Mane-Resume.pdf` with your actual resume.
3. Update the GitHub and LinkedIn links in `index.html`.
4. Add your email/contact information.
5. Edit project and experience descriptions as required.

## GitHub Pages

For a user site, name the repository:

`YOUR-GITHUB-USERNAME.github.io`

Upload these files to the repository and enable GitHub Pages from:

Settings > Pages > Deploy from a branch > main > /(root)

Your website will then be available at:

`https://YOUR-GITHUB-USERNAME.github.io/`
